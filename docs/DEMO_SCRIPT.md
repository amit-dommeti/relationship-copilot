# Two-Minute Demo

Use `?demo=1`; every contact and message is fictional.

1. **Today:** show the three-person shortlist and explain one recommendation.
2. **Circles:** open Square crew. Notice that people now at Stripe or Block still share a past chapter.
3. **Composer:** open Maya, click Help me start, and edit a sentence. State honestly whether this is a configured AI draft or a local starter.
4. **Reply loop:** mark a message sent, open Conversation, save a reply, and set a reminder. Download the calendar file.
5. **Connections:** show the official US import flow and preview a ZIP. Explain the lack of real-time personal LinkedIn access.
6. **Privacy:** leave demo. Real data has not been populated by the fictional session.

Do not send a real LinkedIn message during a demo. The app never sends for you.
